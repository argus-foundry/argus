## Decisions

- **Used tokens = latest `last_token_usage.total_tokens`.** This matches [Codex's meter](https://github.com/openai/codex/blob/748ab55ca7de0b647d9a7a9d9a8e70e00f28666d/codex-rs/tui/src/chatwidget.rs#L1168-L1172), including compaction estimates carried only in the total. Missing, null, negative or malformed totals are unmeasured. Cumulative `total_token_usage` is never used.
- **Window = `info.model_context_window`.** Missing or zero leaves `window_tokens` and `percent` null; percent is derived only from a measured count and a known window, rounded to 0.1.
- **Session scoping.** The thread comes from the task's own account's `state_5.sqlite` (via `CodexHomeForTask`), matched on the task's worktree. A recorded `SessionID` selects only that thread and only if it ran in this worktree, so a replaced or foreign session yields null. With no recorded id (in-progress tasks have none yet) the most recently updated main CLI thread in the worktree is used. Its session metadata must establish creation at or after the running process start; older conversations are hidden until the new launch creates its own thread.
- **Bounded reads.** Only the last 1 MiB of the rollout is parsed; a window with no usable event is "unmeasured". The rollout must be a regular `rollout-*.jsonl` file in the account's source-home or exact derived Argus overlay sessions or archived_sessions directory. A bounded first-record read verifies session metadata ID and cwd. Nonblocking kernel openat traversal rejects FIFOs and file symlinks; session-directory aliases used by Argus overlays remain supported.
- **Live vs recorded.** `live` requires current launch authority and no pending restart, independently of measurement age. For unpinned sessions, metadata creation must be at or after the current process start. Replaced context is hidden; inactive sessions retain recorded data with `live=false`.
- **Event.** Emitted from the existing 5s idle-watcher tick, deduplicated on `measured_at`, identity-only payload. State for exited tasks is pruned.
- **Deviation:** the ticket suggests the stale case "may" return null; we return the recorded snapshot with `live=false`, matching the Claude behaviour already shipped.

- **Index reads preserve WAL.** The index and existing WAL/SHM/journal sidecars receive nonblocking regular-file preflight before a normal read-only SQLite connection. The owner-controlled check-then-open replacement race is accepted; descriptor-path aliases that hide uncheckpointed WAL are not used.
- **Capture selects the same main CLI source as context discovery.** A newer subagent must never become the task's captured session ID. Existing already-miscaptured IDs are not rewritten by this change.
