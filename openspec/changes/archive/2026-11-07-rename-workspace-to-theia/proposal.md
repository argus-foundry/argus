# Name the optional desktop workspace Theia

## Why

The optional desktop web client needs a distinct identity alongside Argus and Hera.

## What Changes

Name the optional client Theia at its identity boundaries. Update browser title owners, the header brand and accessible name, diagnostic title, startup announcement, current document introductions, README Reference entry, gotchas heading and index label, and the base spec Purpose. Preserve attention counts and favicon behavior. Update existing browser assertions and verify compact header geometry.

## Impact

Only the optional frontend, its tests and current documentation change. The desktop-web-workspace capability retains its identifier. No daemon REST contract changes, so the TUI, original SPA and macOS app need no changes. Implementation identifiers, paths, commands, origins, storage keys, push worker paths and existing archives remain unchanged. Dedicated visual assets remain out of scope.
