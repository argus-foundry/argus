# Reject Codex rollout directory aliases

Approved by fix round 2. A rooted source home alone permits sessions -> . and widens the source read boundary to credentials. Require real, non-symlink directory components and tie opened directory handles to their checked identities. Source file opens must reject symlinks too. Bind destination publication to a checked parent directory and retain its existing symlink rejection.

The existing abstractions remain Codex conversation transfer, source sessions storage, and destination publication. This change strengthens the directory admission policy and its opened-handle contract; it adds no endpoint, frontend UI or supervisor behavior. Existing Web ENG-1082, TUI ENG-1093 and Mac UI exclusions remain unchanged.
