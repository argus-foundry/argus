# Theia

- **Serve this client through its loopback development server, not file URLs or direct cross origin API calls.** The unchanged daemon does not expose `X-Output-Total` through CORS, so the development proxy preserves the snapshot to SSE byte cursor handoff without a backend change.
- **Automatic PTY fitting must settle for 400 ms and check fresh runtime state before resizing.** The Claude path can stop/resume a process, so defer known busy sessions, never resize hidden/cache-suspended views, serialize requests and coalesce changes; explicit Fit remains a manual fallback.
- **Stopped terminal catchup must tolerate a size 404 and render the final log before publishing ended.** Keep retained dimensions for recorded output; the session can disappear while its persisted log remains available.
- **Cap unacknowledged live terminal writes at 2 MiB, including the in-flight xterm write.** Close SSE before admitting an overflowing frame, drain accepted writes, then resume through bounded cursor catchup; retain the cursor before the rejected frame so split escape sequences stay ordered.
- **Reconnect must refresh the existing output snapshot and cursor.** A replacement process can reset the log and ring counters, and the current API provides no process identity; carrying an old cursor forward can silently miss output. Fresh replay is bounded by the existing API history limit.
- **Compose must honor the terminal's bracketed paste mode.** Plain shells can interpret unsupported paste markers as command text, and multiline compose is rejected when bracketed paste is unavailable. Canceled sends retain the draft because bytes may have reached the old task before browser cancellation.
- **Dictation requires focus on the native composer textarea after explicit task selection.** Restore that focus after submission without stealing it from another task or control; clipboard newlines are draft content, while Enter sends only outside IME composition and Shift+Enter stays a newline.
- **A focused Chrome textarea can receive Wispr paste events without native insertion.** Explicitly insert event plaintext once, using the browser editing command for undo and range replacement if it makes no change; capture the draft on both paths without redirecting paste from other editable controls or the terminal.
- **Ordinary reconnect supersedes rerender recovery ownership as well as its version.** Cancel the old timer and clear its recovery flag; delayed recovery completion must check the version before changing that flag or the next rerender can remain permanently disconnected.
- **Directory listing paths use the same git quoting as status paths.** Decode `Files[].Path` with `gitPath` before displaying it or passing it to the diff endpoint, including UTF-8 octal and tab escapes.
- **A non-auth project list failure must not discard a successful task read.** Fall back to task groups on connect and retain only the current connection's last project list on refresh, with a project warning; propagate auth and abort errors and apply results only behind the existing generation guards.
- **File drops need a window capture guard before xterm or browser defaults.** Prevent file drag/drop navigation even outside upload targets, leave text drags native, and tolerate a Window target that is not a DOM Node.
- **Attachments retain their captured task through uploads and sends.** Removal/disconnect abort requests and release timers/object URLs, but cannot delete a saved file; canceled uploads may have completed and require checking Files before retrying.
- **Rail archive actions must capture their own task and remain sibling buttons to selection.** After a confirmed archive, update the retained main task, header and input restrictions before refreshing; a failed refresh must not select another task or discard the viewer. Preserve archive-button focus when rebuilding the rail during periodic refresh.
- **Rail action centering must exclude the row gap, and hover must belong to the row wrapper.** Otherwise the sibling archive button loses alignment or clears the highlight when the pointer leaves the selection button.
- **Workspace columns need named grid slots when hidden rails retain zero-width tracks.** Automatic placement moves the remaining terminal into a collapsed rail slot and expands tools into the wrong column; keep wide terminal and diff scrolling inside their viewers, and constrain unbroken labels locally.
- **Compact header widths must accommodate Restore layout, both Show labels and Disconnect.** The default labels alone do not expose the full minimum width at 320 px.
- **General saves must send only their owned partial settings fields.** Round-tripping the GET response includes sandbox and causes a master-only authorization check even when the user changed only a default or KB preference.
- **Project PUT replaces the exposed configuration, and POST also upserts names.** Preserve returned overrides and check duplicate names; profile assignments are not exposed by this API and are reset on edit, so the editor must disclose that inherited limitation.
- **Settings cancellation needs generation guards on busy/status callbacks as well as data.** A delayed save completion must not unlock or overwrite a newer section, and a drawer's handled Escape must not also close Settings.
- **Store credentials only after successful connection, in `argus-workspace-token`, with every storage operation guarded.** Unchecked Remember or blocked storage keeps the token in memory; drafts remain memory-only.
- **Clear saved tokens on explicit disconnect, successful connection with Remember unchecked, or connection-time 401/403 rejection.** Network and 5xx errors retain a saved token for retry; pagehide disposes viewers without clearing storage, and back-forward cache restoration reloads to reconnect.
- **Derive workspace parents from live Hera role task bindings and orchestrator bridge role IDs, never names or base branches.** A task may bind into multiple orchestrators or share a worker/coordinator bridge, so choose one deterministic parent and reject self-links and cycles; archive/search filtering must promote children whose parent is absent.
- **Record task disclosure state synchronously on activation, not the deferred native toggle event.** A search or refresh can replace the details node before its toggle event fires, losing the user's collapse choice; the summary remains the native keyboard target and selection/archive stay separate buttons.
- **Task REST now exposes explicit Result failures as `failure`, while workspace failure presentation remains deferred to ENG-1072.** Current compact icons still use the Hera roster. PR closure and merge remain combined as `merged-closed`; keep that state accurately labeled and attention above all other active states.

Info shares one identity read per selection until explicit refresh or a relevant mutation, skips unchanged or hidden renders, and announces retryable failures with unavailable values; a generic whole-task overwrite is not a runtime model-switch contract.
- **The file picker must use the same captured-task attachment path as drops and paste.** Reset the native input after each choice so choosing the same file again produces a change event.
- **Task workflow status is not session activity or proof of a PR.** Use live/non-idle flags for the working Scribe; keep its fixed 16px SVG slot, visually constant root animation for browser activity assertions, and disable root and descendant animations together for the completed reduced-motion frame. `in_review` alone has no PR glyph, and `complete` has its own completion label.

- **Usage first pages resolve the current session; older pages pin the returned session ID.** Cancel and fence on selection or lifecycle changes, reject mismatched page identities, and keep cached input a subset of inclusive input.

- **Rail refresh must preserve scroll independently of focus restoration.** Archive/restore can remove the focused row or move rows above the viewport; keep the main task separate from filtered rail highlighting and restore the list scroll after replacing its children.
- **Generic raw task PUT is a whole-record overwrite, not a safe task editor.** Branch, base branch, worktree and account are locked to stored values, while unrelated runtime fields can race; use targeted rename/status/session/account endpoints and show model/backend/sandbox/base-branch facts read-only.

- **Account movement is Claude-only and can restart the session after persisting the account.** Verify backend kind and compatible accounts from their REST rosters, keep force opt-in, and treat a failed response as unconfirmed rather than automatically retrying a possibly completed move.

- **System polling belongs to both section visibility and browser-tab visibility.** Cancel the request and timer on hide/destroy, and schedule the next poll after the prior read settles so slow responses cannot overlap or redraw a different section.

- **Capture terminal shortcuts before xterm, using the exact modifier allowlist.** Scroll with xterm scroll APIs, never synthesized key input; global browser equivalents stay out of terminal and editable input so composition, paste and ordinary control keys retain their owners.
- **Update uses the daemon's saved source path, not the current input value.** Block Update until the displayed path is saved, and treat incomplete or interrupted update responses as uncertain rather than retrying; the build may continue server-side and restart the daemon.
- **Cancel the successful-update reload timer when its section is destroyed.** Restart is requested, not proven complete by the response, and navigating away or disconnecting must not trigger a later reload that discards a new draft.
- **Claude session selection can restart a task, so a failed or canceled request is unconfirmed.** Capture the task before opening, fence late callbacks and reconnect output only after a confirmed switch; the daemon's backend capability and 400 response remain authoritative.
